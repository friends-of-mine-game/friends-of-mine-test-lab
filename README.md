# Friends of Mine · Test Lab

Laboratorio público y ligero para ejecutar pruebas humanas del proyecto Friends of Mine desde móvil.

## Objetivo

`idea → test versionado → enlace → respuestas estructuradas → análisis → decisión`

Este repositorio **no contiene el GDD ni código del producto**. Solo contiene instrumentación y cuestionarios que se decida hacer públicos.

## Privacidad y respuestas

En el piloto de socios las respuestas se guardan automáticamente en `localStorage` del navegador y al finalizar se exportan como JSON. No se envían a ningún servidor. Para pruebas externas se añadirá un receptor automático antes de compartir el enlace por WhatsApp.

## Publicación

GitHub Pages se despliega mediante `.github/workflows/pages.yml`. La URL prevista es `https://friends-of-mine-game.github.io/friends-of-mine-test-lab/`.
